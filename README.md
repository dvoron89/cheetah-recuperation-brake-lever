# cheetah-recuperation-brake-lever

Набор для переноса рекуперационного тормоза Arctic Leopard Cheetah под большой палец

Дополнительно для сборки потребуется:
- винт М6х25 – 3 шт
- гайка М6 – 3 шт
- магнит цилиндрический 3х4мм (диаметр 3 мм, высота 4 мм) – 2 шт

От оригинального рычага рекуперационного тормоза используется:
- датчик Холла с корпусом и проводкой и два крепежных самореза
- торсионная пружина
- винт М5 с гайкой для крепления рычага
